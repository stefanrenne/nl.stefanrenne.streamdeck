Styr Homey øjeblikkeligt fra dit Stream Deck — direkte via dit LAN.
Gør hver LCD-knap til en kraftfuld smart home-trigger.

Konfiguration:
Indstil det på din måde.
Upload brugerdefinerede billeder, byg personlige dashboards og tildel unikke nyttelaster til hvert knapklik.
Et tryk — og Homey klarer resten.

Krav:
- Stream Deck Studio
- Stream Deck Network Dock, med en af følgende enheder:
	- Stream Deck Module 6
	- Stream Deck Module 15
	- Stream Deck Module 32
	- Stream Deck Mini
	- Stream Deck Classic
	- Stream Deck Scissor Keys
	- Stream Deck XL
	- Stream Deck neo (kun LCD-knapper understøttes)
	- Stream Deck + (kun LCD-knapper understøttes)

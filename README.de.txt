Steuere Homey direkt über dein Stream Deck — einfach über dein LAN.
Verwandle jeden LCD-Button in einen leistungsstarken Smart-Home-Trigger.

Konfiguration:
Richte es ganz nach deinen Wünschen ein.
Lade benutzerdefinierte Bilder hoch, erstelle personalisierte Dashboards und weise jedem Tastendruck eindeutige Payloads zu.
Ein Tipp — und Homey erledigt den Rest.

Anforderungen:
- Stream Deck Studio
- Stream Deck Network Dock, mit einem der folgenden Geräte:
	- Stream Deck Module 6
	- Stream Deck Module 15
	- Stream Deck Module 32
	- Stream Deck Mini
	- Stream Deck Classic
	- Stream Deck Scissor Keys
	- Stream Deck XL
	- Stream Deck neo (nur LCD-Tasten werden unterstützt)
	- Stream Deck + (nur LCD-Tasten werden unterstützt)

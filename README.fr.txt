Contrôlez Homey instantanément depuis votre Stream Deck — directement via votre LAN.
Transformez chaque bouton LCD en un puissant déclencheur pour votre maison connectée.

Configuration :
Configurez-le à votre façon.
Téléchargez des images personnalisées, créez des tableaux de bord personnalisés et attribuez des charges utiles uniques à chaque appui de bouton.
Une touche — et Homey s'occupe du reste.

Prérequis :
- Stream Deck Studio
- Stream Deck Network Dock, avec l'un des appareils suivants :
	- Stream Deck Module 6
	- Stream Deck Module 15
	- Stream Deck Module 32
	- Stream Deck Mini
	- Stream Deck Classic
	- Stream Deck Scissor Keys
	- Stream Deck XL
	- Stream Deck neo (boutons LCD uniquement)
	- Stream Deck + (boutons LCD uniquement)

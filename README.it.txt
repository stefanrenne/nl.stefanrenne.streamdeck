Controlla il tuo sistema domotico Homey direttamente dal tuo Stream Deck — all'istante, tramite la rete locale, senza dipendenze dal cloud.

Ogni pulsante LCD del tuo Stream Deck diventa un potente trigger domotico personalizzabile. Premi un pulsante e Homey esegue i tuoi flow: accendi o spegni le luci, regola le scene, blocca le porte o attiva qualsiasi automazione che hai configurato.

Raggruppa i pulsanti in dashboard, assegna loro immagini personalizzate o testo in tempo reale e lascia che Homey cambi dashboard automaticamente. Ti serve solo uno Stream Deck collegato tramite uno Stream Deck Network Dock.

Documentazione completa, con tutte le schede Flow e i modelli di Stream Deck supportati: https://github.com/stefanrenne/nl.stefanrenne.streamdeck

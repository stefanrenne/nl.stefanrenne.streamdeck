Controlla il tuo sistema domotico Homey direttamente dal tuo Stream Deck — all'istante, tramite la rete locale, senza dipendenze dal cloud.

Ogni pulsante LCD del tuo Stream Deck diventa un potente trigger domotico personalizzabile. Premi un pulsante e Homey esegue i tuoi flow: accendi o spegni le luci, regola le scene, blocca le porte o attiva qualsiasi automazione che hai configurato.

---

Funzionalità:

Dashboard
Organizza i tuoi pulsanti in più dashboard con nome e passa da una all'altra tramite un Flow Homey. Crea una dashboard "Mattina", una "Serata Cinema" o qualsiasi layout si adatti alla tua routine — poi lascia che Homey cambi automaticamente in base all'orario, alla presenza o a qualsiasi altro trigger.

Immagini personalizzate
Carica le tue immagini JPG o PNG e assegnale ai pulsanti. Dai a ogni pulsante un'icona chiara e personalizzata così sai sempre a colpo d'occhio cosa fa.

Variabili dinamiche
Crea pulsanti variabile che mostrano due righe di testo in tempo reale — temperatura, stato di un dispositivo, conto alla rovescia o qualsiasi valore prodotto dai tuoi flow. Aggiorna il testo in tempo reale tramite le azioni del Flow, così il tuo Stream Deck riflette sempre cosa sta succedendo in casa.

Integrazione con i Flow
- Trigger: Reagisci alle pressioni dei pulsanti (premuto, rilasciato, pressione singola, doppia pressione) in qualsiasi Flow Homey. Ogni trigger fornisce il dashboard, il nome dell'immagine, le righe di testo, il payload, la colonna e la riga come token.
- Condizioni: Dirama i tuoi flow in base alla dashboard attualmente attiva.
- Azioni: Passa a qualsiasi dashboard o aggiorna il testo di un pulsante variabile — prima riga, seconda riga o entrambe.

Rilevamento automatico
L'app rileva automaticamente il tuo Stream Deck Network Dock sulla rete locale tramite mDNS, quindi la configurazione richiede pochi secondi.

---

Configurazione:

Apri le impostazioni dell'app in Homey per gestire le tue dashboard, immagini e variabili. Usa il software Stream Deck Studio per assegnare payload e collegare ogni pulsante alla tua configurazione Homey.

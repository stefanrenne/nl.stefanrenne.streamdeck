Bedien Homey direct vanaf je Stream Deck — gewoon via je LAN.
Maak van elke LCD-knop een krachtige trigger voor je slimme huis.

Configuratie:
Stel het helemaal in zoals jij wilt.
Upload eigen afbeeldingen, maak gepersonaliseerde dashboards en koppel unieke payloads aan elke knopdruk.
Eén tik — en Homey doet de rest.

Vereisten:
- Stream Deck Studio
- Stream Deck Network Dock, met een van de volgende apparaten:
	- Stream Deck Module 6
	- Stream Deck Module 15
	- Stream Deck Module 32
	- Stream Deck Mini
	- Stream Deck Classic
	- Stream Deck Scissor Keys
	- Stream Deck XL
	- Stream Deck neo (alleen LCD-knoppen worden ondersteund)
	- Stream Deck + (alleen LCD-knoppen worden ondersteund)

Bedien je Homey slimme woning direct vanaf je Stream Deck — direct, via je lokale netwerk, zonder cloudafhankelijkheid.

Elke LCD-knop op je Stream Deck wordt een krachtige, aanpasbare trigger voor je slimme huis. Druk op een knop en Homey voert je flows uit: lichten aan of uit, scènes aanpassen, deuren vergrendelen of welke automatisering je ook hebt gebouwd.

Groepeer je knoppen in dashboards, geef ze je eigen afbeeldingen of live tekst, en laat Homey automatisch van dashboard wisselen. Je hebt alleen een Stream Deck nodig die via een Stream Deck Network Dock is aangesloten.

Volledige documentatie, met alle Flow-kaarten en de ondersteunde Stream Deck-modellen: https://github.com/stefanrenne/nl.stefanrenne.streamdeck

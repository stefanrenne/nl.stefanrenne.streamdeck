Styr Homey øyeblikkelig fra Stream Deck — rett over LAN.
Gjør hver LCD-knapp om til en kraftig trigger for ditt smarte hjem.

Konfigurasjon:
Sett det opp slik du vil.
Last opp egendefinerte bilder, bygg personlige instrumentbord og tildel unike nyttelaster til hvert knappetrykk.
Ett trykk — og Homey tar seg av resten.

Krav:
- Stream Deck Studio
- Stream Deck Network Dock, med en av følgende enheter:
	- Stream Deck Module 6
	- Stream Deck Module 15
	- Stream Deck Module 32
	- Stream Deck Mini
	- Stream Deck Classic
	- Stream Deck Scissor Keys
	- Stream Deck XL
	- Stream Deck neo (kun LCD-knapper støttes)
	- Stream Deck + (kun LCD-knapper støttes)

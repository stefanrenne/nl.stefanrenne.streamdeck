Steruj Homey natychmiastowo ze swojego Stream Deck — bezpośrednio przez LAN.
Zamień każdy przycisk LCD w potężny wyzwalacz dla inteligentnego domu.

Konfiguracja:
Skonfiguruj po swojemu.
Przesyłaj własne obrazy, twórz spersonalizowane pulpity i przypisuj unikalne dane do każdego naciśnięcia przycisku.
Jedno dotknięcie — a Homey zajmuje się resztą.

Wymagania:
- Stream Deck Studio
- Stream Deck Network Dock, z jednym z następujących urządzeń:
	- Stream Deck Module 6
	- Stream Deck Module 15
	- Stream Deck Module 32
	- Stream Deck Mini
	- Stream Deck Classic
	- Stream Deck Scissor Keys
	- Stream Deck XL
	- Stream Deck neo (obsługiwane tylko przyciski LCD)
	- Stream Deck + (obsługiwane tylko przyciski LCD)

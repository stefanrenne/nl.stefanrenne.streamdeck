Управляйте Homey мгновенно со своего Stream Deck — прямо через локальную сеть.
Превратите каждую LCD-кнопку в мощный триггер для умного дома.

Настройка:
Настройте всё по-своему.
Загружайте собственные изображения, создавайте персональные панели управления и назначайте уникальные данные каждому нажатию кнопки.
Одно нажатие — и Homey сделает всё остальное.

Требования:
- Stream Deck Studio
- Stream Deck Network Dock, с одним из следующих устройств:
	- Stream Deck Module 6
	- Stream Deck Module 15
	- Stream Deck Module 32
	- Stream Deck Mini
	- Stream Deck Classic
	- Stream Deck Scissor Keys
	- Stream Deck XL
	- Stream Deck neo (поддерживаются только LCD-кнопки)
	- Stream Deck + (поддерживаются только LCD-кнопки)

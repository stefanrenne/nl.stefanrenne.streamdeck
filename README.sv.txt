Styr Homey direkt från din Stream Deck — via ditt LAN.
Gör varje LCD-knapp till en kraftfull trigger för ditt smarta hem.

Konfiguration:
Ställ in det precis som du vill.
Ladda upp egna bilder, skapa personliga instrumentpaneler och tilldela unika nyttolaster till varje knapptryckning.
Ett tryck — och Homey tar hand om resten.

Krav:
- Stream Deck Studio
- Stream Deck Network Dock, med en av följande enheter:
	- Stream Deck Module 6
	- Stream Deck Module 15
	- Stream Deck Module 32
	- Stream Deck Mini
	- Stream Deck Classic
	- Stream Deck Scissor Keys
	- Stream Deck XL
	- Stream Deck neo (endast LCD-knappar stöds)
	- Stream Deck + (endast LCD-knappar stöds)
